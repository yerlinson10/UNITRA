## Concepto de marca

### Nombre conceptual: **UNITRA**

**UNI** = unidad física individual
**TRA** = Trade-In / transacción / tracking

La idea es que cada teléfono dentro del sistema es una **unidad trazable**, desde que entra al inventario hasta que se vende.

**UNITRA — Controla cada unidad. Mueve tu negocio.**

### Personalidad

* **Tecnológica**, pero no futurista exagerada.
* **Profesional**, orientada a negocios.
* **Precisa**, porque trabaja con IMEI, seriales y costos.
* **Ágil**, por el flujo POS y Trade-In.
* **Confiable**, porque registra el historial de cada dispositivo.

### Logo

No usaría un teléfono dibujado literalmente.

Crearía un símbolo geométrico formado por **dos elementos que se encuentran**:

**Unidad + Transacción**

Visualmente podría funcionar como:

```text
      ┌───────┐
      │       │
      │   ────┤
      │       │
      └───────┘
```

Pero mucho más refinado y abstracto.

El símbolo tendría una lectura secundaria de:

* dispositivo
* código/IMEI
* intercambio
* movimiento de inventario
* conexión entre compra y venta

Esto permitiría usarlo como **favicon, icono de aplicación, avatar y marca dentro del dashboard**.

---

# Paleta

No usaría los típicos azul + degradados de SaaS.

### Principal

**Ink**
`#111315`

Para navegación, logo y textos importantes.

**Lime**
`#B8E34B`

Como color de acción y elemento distintivo.

### Neutros

`#F5F6F3` — fondo
`#FFFFFF` — superficies
`#E3E5E0` — bordes
`#6B7069` — texto secundario
`#252925` — texto principal

### Estados

`#22A06B` — disponible / operación correcta
`#D97706` — pendiente / reparación
`#DC4444` — devolución / error

La combinación **negro + lima + blanco roto** haría que el sistema se vea bastante más premium y reconocible.

---

# Tipografía

### Headings

**Barlow Condensed SemiBold**

Para números grandes, KPIs y títulos.

Ejemplo:

> INVENTARIO
> **128 UNIDADES**

### Interface

**Inter**

Para tablas, formularios, botones, IMEI, precios y datos.

Esto además encaja muy bien con un sistema administrativo donde existe bastante información estructurada.

# Lenguaje visual del dashboard

La marca debería aparecer principalmente mediante **pequeños detalles**, no llenando toda la interfaz de verde.

Por ejemplo:

```text
┌─────────────────────────────────────────────────────────┐
│ UNITRA                         Buscar...       YL        │
├──────────────┬──────────────────────────────────────────┤
│              │                                          │
│  Dashboard   │  INVENTARIO                              │
│              │                                          │
│  Inventario  │  128 unidades                            │
│              │  ───────────────────────────────────     │
│  Compras     │                                          │
│  Ventas      │  iPhone 13       IMEI      $320   ●      │
│  Trade-In    │  iPhone 14       IMEI      $450   ●      │
│  Caja        │  Samsung S23     IMEI      $390   ●      │
│  Reportes    │                                          │
│              │                                          │
└──────────────┴──────────────────────────────────────────┘
```

El **verde lima aparece para acciones, indicadores y estados**, no como fondo general.

---

# Elemento distintivo de la marca

Haría que el concepto de **IMEI / unidad individual** sea parte del lenguaje gráfico.

Por ejemplo, utilizar pequeñas estructuras:

```text
01 · 02 · 03 · 04 · 05
```

o

```text
UNIT
────
IMEI
```

como recurso visual en:

* tarjetas
* documentos
* facturas
* etiquetas
* pantallas de inventario
* estados de dispositivos

Esto conecta directamente la identidad con el funcionamiento real del sistema.

# Aplicación en módulos

| Módulo      | Identidad                     |
| ----------- | ----------------------------- |
| Dashboard   | KPIs grandes + lime           |
| Inventario  | Tablas limpias + estados      |
| Compras     | Entradas / unidades           |
| Trade-In    | Elementos de intercambio      |
| POS         | Interfaz rápida y contrastada |
| Facturación | Blanco + negro, muy limpia    |
| Caja        | Indicadores financieros       |
| Reportes    | Gráficos sobrios              |
| PDF         | Identidad corporativa         |
| Login       | Logo + símbolo                |

El sistema contempla precisamente inventario por IMEI, estados como `available`, `sold`, `in_repair` y `returned`, además del flujo de Trade-In y facturación.
